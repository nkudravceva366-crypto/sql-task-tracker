# Week 06 — Functions (1–4)

This folder contains solved SQL tasks for Week 06 based on the educational airbase database.

## Topics

* SQL functions
* `CREATE FUNCTION`
* function parameters
* `RETURNS TABLE`
* `CASE`
* reusable database logic
* creating objects in the `sandbox` schema
* function calls with test parameters

## Naming Convention

Objects are created using snake_case according to the course naming convention:

* `f` — function

Examples:

* `sandbox.kudravceva_f_client_grade`
* `sandbox.kudravceva_f_ticket_refund`
* `sandbox.kudravceva_f_free_seats`
* `sandbox.kudravceva_f_flight_passengers`

## Files

* `tasks_1_4.sql` — solutions for tasks 1–4

## Notes

After review and moving tasks to `Done`, created database objects should be deleted using the cleanup commands included at the end of the SQL script.
