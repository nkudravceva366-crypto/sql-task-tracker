# Week 05 — Views (1–3)

This folder contains solved SQL tasks for Week 05 based on the educational airbase database.

## Topics

* views
* `CREATE VIEW`
* analytical views
* masked data
* financial reports
* price history analysis
* reusable query logic
* creating objects in the `sandbox` schema

## Naming Convention

Objects are created using snake_case according to the course naming convention:

* `v` — view

Example:

* `sandbox.kudravceva_v_today_flights_masked`

## Files

* `tasks_1_3.sql` — solutions for tasks 1–3
